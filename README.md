# Iolite Cipher

Full-colour Python 3 neon falling-glyph word arcade for [ElbowOS](https://x.com/ElbowOS).

Letters rain down five indigo lanes. Slide the catcher and forge the target word
one glyph at a time. Wanted letters glow gold. A miss breaks the streak.

A / D or arrows move the catcher. R restarts.

## Play

```
pip install -r requirements.txt
python3 iolite_cipher.py
```

## Record a 9:16 reel

```
python3 iolite_cipher.py --record
```

Writes a 15s 1080×1920 H.264 MP4 (override path with `ELBOWOS_MP4`).
